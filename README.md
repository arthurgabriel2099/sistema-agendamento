# Sistema de Agendamento e Orçamento de Eventos

## Objetivo
Sistema em linguagem C para agendar eventos e calcular o orçamento.

## Funcionalidades
- Inserir tipo de solenidade
- Inserir data do evento
- Número de convidados
- Escolher o local do evento
- Ver orçamento total
- Confirmar ou cancelar evento
